📞 Call Management System - Gestión de Extensiones Telefónicas
Sistema de gestión de extensiones SIP para centrales telefónicas VoIP

📋 Descripción
Este proyecto es una aplicación backend desarrollada con Spring Boot para la gestión integral de extensiones telefónicas en entornos VoIP. Permite administrar usuarios, extensiones SIP, roles y registros de llamadas de manera eficiente y escalable.

Originalmente desarrollado como parte de un sistema de telecomunicaciones, este repositorio ha sido reorganizado para ofrecer una solución modular y fácil de implementar en entornos empresariales.
